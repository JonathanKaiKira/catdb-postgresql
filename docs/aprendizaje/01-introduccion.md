# 01 · Introducción

CatDB reúne el historial de cuidado de varios gatos ficticios. Responde preguntas como quién cuida a Luna, cómo cambió su peso, cuánto costó su cuidado y qué seguimientos quedaron registrados.

PostgreSQL almacena y valida los datos. SQL crea las tablas y consulta las relaciones. Podman permite repetir la demostración y DBeaver permite navegar y ejecutar SQL visualmente. Git conserva decisiones y GitHub Actions ejecuta la suite tras cada cambio.

Empieza con la [guía visual](05-guia-visual.md). Busca la tabla `cats` y el registro `LUNA`. Después localiza ese gato en `weights` mediante su `cat_id`.
